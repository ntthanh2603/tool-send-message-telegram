# 🤖 Tool Send Message Telegram 📩

## 📋 Hướng dẫn cách dùng

### 🔑 Đăng ký bot trên Telegram:

1. 🔍 Tìm kiếm `@BotFather` trong thanh tìm kiếm
2. 📝 Nhập `/start` để hiện menu
3. ➕ Nhập `/newbot` để tạo bot mới
4. ✏️ Nhập tên bot, ví dụ: `auto_send_message`
5. 🏷️ Nhập username của bot, ví dụ: `tuanthanh2603_bot` (Ở bước này nếu tên đã sử dụng thì nhập tên khác)

### 💻 Sử dụng source code để làm các công việc tự động:

1. 📥 Clone repo sau:

```bash
git clone https://github.com/ntthanh2603/tool-send-message-telegram.git
cd tool-send-message-telegram
```

2. 🔧 Tạo môi trường:

```bash
python3 -m venv venv
```

3. ▶️ Kích hoạt môi trường:

```bash
source venv/bin/activate
```

4. 📦 Cài đặt thư viện cần thiết:

```bash
pip install -r requirements.txt
```

5. 🚀 Chạy dự án:

```bash
python3 bot_tele.py
```

### 🧪 Bạn có thể thử nghiệm:

1. 👥 Vào group có bot theo link: https://t.me/bot_telegram_snet
2. 🔍 Nhập "/menu" để có thể xem các lựa chọn
